# Valenzuela & Asociados — Landing Page Jurídica ⚖️🏛️

Landing page y sitio web corporativo de alta gama para bufete de abogados y servicios jurídicos especializados.

## 🚀 Características
- **Diseño Visual de Prestigio**: Estética oscura en azul marino profundo (`#070B19`), acentos en oro pulido (`#C5A059`) y tipografía clásica (*Cinzel* + *Plus Jakarta Sans*).
- **Calculadora Interactiva de Viabilidad Legal**: Evaluación preliminar instantánea de la solidez procesal de un caso.
- **Áreas de Especialización**: Secciones completas para Derecho Penal, Herencias/Civil, Laboral, Familia, Mercantil y Accidentes/Negligencias.
- **Métricas de Autoridad**: Respaldo numérico de años de experiencia, porcentaje de éxito y casos resueltos.
- **Formularios de Consulta Confidencial**: Formulario de evaluación rápida en Hero y formulario detallado con aceptación RGPD y modal interactivo.
- **Acordeón FAQ Interactivo**: Respuestas a honorarios, cuota litis, confidencialidad y urgencias 24/7.
- **Botón Flotante de Urgencias WhatsApp**: Asistencia directa con un clic.
- **Optimización SEO y Accesibilidad**: Semantic HTML5, Schema.org `LegalService` JSON-LD, metadatos OpenGraph y diseño 100% responsivo.
